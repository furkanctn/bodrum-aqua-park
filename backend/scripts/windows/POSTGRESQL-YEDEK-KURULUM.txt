================================================================================
Bodrum Aqua Park — PostgreSQL günlük yedekleme (Windows sunucu)
================================================================================

Ne yapar?
  • bodrum_aqua_park veritabanının yedeğini alır
  • Her gün 22:45'te otomatik çalışır (kart sıfırlama 23:00'ten önce)
  • Yedekler: C:\BodrumAquaPark\backup\
  • Son 30 yedek saklanır, eskiler silinir

Ayrıca (rolling — 30 dk):
  • BodrumDbRollingBackup.bat her 30 dk aynı dosyanın üzerine yazar
  • Dosya: C:\BodrumAquaPark\backup\bodrum_aqua_park_rolling.backup
  • Amaç: en fazla ~30 dk öncesine dönebilmek

Proje dosyaları (NightlyCardReset klasörü):
  • BodrumDbBackup.bat / BodrumDbBackup-Zamanla.ps1           → günlük 22:45
  • BodrumDbRollingBackup.bat / BodrumDbRollingBackup-Zamanla.ps1 → her 30 dk
  • POSTGRESQL-YEDEK-KURULUM.txt → bu dosya

Sunucu bilgileri (yedek script sunucunun kendisinde çalışır):
  • Host:     127.0.0.1
  • Port:     5433  (PostgreSQL farklı porttaysa değiştirin; çoğu kurulumda 5432)
  • Database: bodrum_aqua_park
  • User:     postgres
  • Şifre:    POS config ile aynı

Not: 100.78.186.3 (Tailscale) kullanmayın — pg_hba.conf reddeder.
     NightlyCardReset.bat uzak IP kullanıyor olabilir; yedek için localhost şart.

================================================================================
1) DOSYALARI SUNUCUYA KOPYALA
================================================================================

  C:\BodrumAquaPark\backup\ klasörüne kopyalayın:

      BodrumDbBackup.bat
      BodrumDbBackup-Zamanla.ps1
      POSTGRESQL-YEDEK-KURULUM.txt

================================================================================
2) AYARLARI KONTROL ET
================================================================================

  Not Defteri ile BodrumDbBackup.bat açın:

      set "PGHOST=..."
      set "PGPORT=..."
      set "PGPASSWORD=..."
      set "BACKUP_DIR=C:\BodrumAquaPark\backup"
      set "KEEP_COUNT=30"

  NightlyCardReset.bat ile aynı host/port/şifre olmalı.

================================================================================
3) MANUEL TEST
================================================================================

      cd C:\BodrumAquaPark\backup
      BodrumDbBackup.bat

  Başarılıysa klasörde şuna benzer dosya görünür:

      bodrum_aqua_park_2026-07-25_220001.backup

  Log:

      C:\BodrumAquaPark\backup\bodrum-db-backup.log

================================================================================
4) OTOMATİK ZAMANLAMA (her gün 22:45)
================================================================================

  Yönetici PowerShell:

      cd C:\BodrumAquaPark\backup
      Set-ExecutionPolicy -Scope Process Bypass
      .\BodrumDbBackup-Zamanla.ps1

  Görev adı: BodrumAquaPark-DbBackup

  Hemen test:

      Start-ScheduledTask -TaskName 'BodrumAquaPark-DbBackup'

================================================================================
5) GERİ YÜKLEME
================================================================================

  POS uygulamalarını durdurun, sonra:

      set PGPASSWORD=123123
      "C:\Program Files\PostgreSQL\16\bin\pg_restore.exe" ^
        -h 100.78.186.3 -p 5433 -U postgres -d bodrum_aqua_park ^
        --clean --if-exists ^
        C:\BodrumAquaPark\backup\bodrum_aqua_park_XXXX.backup

  (host/port/sürümü kendi sunucunuza göre düzenleyin)
